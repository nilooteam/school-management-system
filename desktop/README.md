# نسخه دسکتاپ ویندوز بهار

این پوشه پوسته دسکتاپ Electron برای سامانه آنلاین بهار را فراهم می‌کند. داده‌ها و احراز هویت همچنان توسط وب‌اپلیکیشن اصلی مدیریت می‌شوند؛ این برنامه دیتابیس محلی جداگانه‌ای ایجاد نمی‌کند.

## راه‌اندازی توسعه

1. وابستگی‌های مخزن را با Bun نصب کنید.
2. نشانی سامانه را در اولین اجرای برنامه وارد کنید.
3. اجرا: `bun run desktop`

## ساخت نصب‌کننده ویندوز

روی ویندوز یا در محیط Windows CI اجرا کنید:

```bash
bun install
bun run desktop:dist
```

خروجی در پوشه `release` ساخته می‌شود.

## امنیت و اتصال

- اولین اجرا نشانی HTTPS سامانه را درخواست می‌کند و آن را در پوشه تنظیمات کاربر ویندوز ذخیره می‌کند.
- فقط همان مبدأ مجاز است داخل پنجره برنامه باز شود.
- پنجره‌های جدید و پیوندهای HTTPS خارجی به مرورگر پیش‌فرض سیستم فرستاده می‌شوند.
- دسترسی Node.js به محتوای وب غیرفعال است و ارتباط محدود preload از IPC استفاده می‌کند.
- برای اجرای محلی، نشانی‌های localhost با HTTP نیز مجاز هستند.

این نسخه یک پوسته متصل به وب است؛ برای ورود و کارکرد کامل باید دامنه عمومی و HTTPS سامانه بهار فعال باشد.
