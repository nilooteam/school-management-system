# نسخه دسکتاپ ویندوز بهار

این پوشه پوسته دسکتاپ Electron برای اجرای سامانه بهار در یک پنجره مستقل ویندوز است. برای استفاده نیازی به باز کردن مرورگر نیست؛ بااین‌حال این نسخه برای نمایش و پردازش اطلاعات به اینترنت و نشانی HTTPS سامانه آنلاین نیاز دارد و در حال حاضر نسخه آفلاین یا دیتابیس محلی مستقل نیست.

## راه‌اندازی توسعه

1. وابستگی‌های مخزن را با Bun نصب کنید.
2. برنامه را با `bun run desktop` اجرا کنید.
3. در اولین اجرا، نشانی HTTPS سامانه را وارد کنید. نشانی در پوشه تنظیمات کاربر همان دستگاه ذخیره می‌شود.

## ساخت نصب‌کننده ویندوز

ساخت نصب‌کننده فقط روی ویندوز یا محیط Windows CI انجام شود:

```bash
bun install
bun run desktop:dist
```

خروجی در پوشه `release` قرار می‌گیرد. این دستور در این تغییرات اجرا نشده است.

## امنیت و اتصال

- اولین اجرا نشانی سامانه را دریافت و در تنظیمات محلی کاربر ذخیره می‌کند.
- فقط همان مبدأ مجاز است داخل پنجره برنامه باز شود.
- پنجره‌های جدید و پیوندهای HTTPS خارجی به مرورگر پیش‌فرض سیستم فرستاده می‌شوند.
- دسترسی Node.js به محتوای وب غیرفعال است؛ ارتباط preload محدود و از طریق IPC کنترل‌شده انجام می‌شود.
- اجرای هم‌زمان چند نمونه برنامه جلوگیری می‌شود.
- برای توسعه محلی، نشانی‌های localhost با HTTP نیز مجاز هستند.

این نسخه یک برنامه دسکتاپ متصل به وب است؛ برای ورود و کارکرد کامل باید دامنه عمومی و HTTPS سامانه بهار فعال باشد.
